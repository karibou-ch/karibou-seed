# **KARIBOU — PLAN DE MIGRATION UX 2026**

## **Objectif**

Transformer l'architecture UX de Karibou pour passer d'une navigation **orientée marchés** à une navigation **orientée intentions client**, avec une architecture de **navigation à 3 niveaux**.

---

## **1. ARCHITECTURE NAVIGATION 3 NIVEAUX**

### **1.1 Vue d'ensemble**

| Niveau | Description | Implémentation |
|--------|-------------|----------------|
| **N1 - Services** | Navigation inter-services (intentions) | `NAV_SERVICE_ITEMS` - variable homogène |
| **N2 - Contexte** | Navigation intra-service | Panel Side par composant |
| **N3 - Opérationnel** | Compte, commandes, factures | Drawer/Modal dédié |

### **1.2 Niveau 1 : Services (NAV_SERVICE_ITEMS)**

```
┌──────────────────────────────────────────────────────────────────────────┐
│                        NAV_SERVICE_ITEMS                                 │
├──────────┬──────────┬──────────┬──────────┬──────────────────────────────┤
│ 🏠 Hub   │ 🛒 Courses│ 🎉 Buffet│ 🔄 Auto  │ 💬 James                     │
│ /        │ /home    │ /buffet  │ /subs    │ /assistant                   │
└──────────┴──────────┴──────────┴──────────┴──────────────────────────────┘
```

### **1.3 Niveau 2 : Contexte Service (Panel Side)**

| Service | Panel Side | Panel Right |
|---------|------------|-------------|
| `/home` | Categories, Boutiques, Thèmes, Favoris | Calendrier, Aide |
| `/buffet` | Formulaire, Kits, Produits buffet | Récapitulatif, Assistant |
| `/subscriptions` | Contrats, Créer, Historique | Calendrier, Assistant |
| `/assistant` | Questions rapides, Historique | Produits suggérés |

### **1.4 Panier vs Contrats**

| Service | Panier | Explication |
|---------|--------|-------------|
| `/home` | ✅ | Ajout produits → /cart/default |
| `/buffet` | ✅ | Kits click-buy → /cart/default |
| `/subscriptions` | ❌ | **Contrats** (pas un panier) |
| `/assistant` | ✅ | Panier vocal → /cart/default |

**⚠️ Subscriptions = Contrats**
- Configuration : récurrence + produits + adresse
- Modifiable/pausable à tout moment

## **3. ÉTAT ACTUEL vs ÉTAT CIBLE**

### **3.1 Routes - Comparaison**

| Route | État Actuel | État Cible | Statut |
|-------|-------------|------------|--------|
| `/store/:store/` | Paramètres user | Hub intentions | ✅ FAIT |
| `/store/:store/home` | Marché | "Faire mes courses" | ✅ OK |
| `/store/:store/home/business` | ProductList | DEPRECATED | ✅ REDIRECT |
| `/store/:store/buffet` | N'existe pas | "Recevoir un buffet" | ✅ FAIT |
| `/store/:store/subscriptions` | Abonnements | "Ne plus oublier" | 🔄 LABELS |
| `/store/:store/assistant` | James | Assistant NEUTRE | 🔜 AJUSTER |

### **3.2 Configuration Backend**

**État actuel :**
```
config
├── tagLine: { h, t, p, image }        Landing
├── about: { h, t, p, image }          À propos
├── subscription: { h, t, p, article } Abonnements
└── business: { h, t, p, article }     B2B → DEPRECATED
```

**État cible :**
```
config
├── tagLine, about, subscription       (conservés)
├── business                           (mappé → buffet)
└── intentions                         (NOUVEAU)
    ├── courses: { title, subtitle, cta, image }
    ├── buffet: { title, subtitle, cta, image }
    ├── subscription: { title, subtitle, cta, image }
    └── assistant: { title, subtitle, questions[] }
```

## **4. ASSISTANT : NEUTRE vs ENCADRÉ**

### **4.1 Deux modes complémentaires**

| Mode | Localisation | Questions | Contexte |
|------|--------------|-----------|----------|
| **NEUTRE** | `/assistant` | Tous domaines | Aucun prédéfini |
| **ENCADRÉ** | Widget dans pages | Filtrées par domaine | Automatique |

### **4.2 Questions par domaine**

```
NEUTRE (assistant/james)
├── 🧺 Apéro terroir → "Je cherche des produits pour un apéro"
├── 🍳 Recette du jour → "Une recette avec mon panier"
├── 📅 Disponible demain ? → "Qu'est-ce qui est disponible ?"
├── 🎉 Buffet 20 pers. → "Un buffet pour 20 personnes"
└── 🔄 Commandes auto → "Comment fonctionnent les abos ?"

ENCADRÉ /home
├── 🥗 Idée repas → Suggestions selon panier
├── 🧺 Produits saison → Fruits/légumes du moment
└── ❓ Aide commande → Vérification panier

ENCADRÉ /buffet
├── 🎉 Buffet X pers. → Estimation quantités
├── 🧀 Plateau fromages → Recommandations
└── 🍷 Sélection vins → Accords mets-vins

ENCADRÉ /subscriptions
├── 🍞 Pain chaque semaine → Configuration fréquence
├── 🥬 Panier légumes → Produits éligibles
└── ❓ Comment ça marche → Explication contrats
```
